卫星运动轨道

开普勒三定律（卫星轨道力学基础）

背景：由德国天文学家 约翰内斯·开普勒（Johannes Kepler，1571–1630） 于1609–1619年提出，基于第谷·布拉赫的观测数据总结得出，描述了行星绕太阳运动的规律，后推广应用于所有人造地球卫星的轨道运动。

开普勒第一定律（轨道定律）

表述：所有行星绕太阳运动的轨道都是椭圆，太阳位于椭圆的一个焦点上。

推广到卫星：

人造地球卫星绕地球运行的轨道是椭圆，地球位于椭圆的一个焦点上。

关键参数：

  • 近地点（Perigee）：轨道上距地心最近的点
  • 远地点（Apogee）：轨道上距地心最远的点
  • 半长轴（a）：椭圆长轴的一半，决定轨道大小

开普勒第二定律（面积定律）

表述：行星与太阳的连线在相等时间内扫过相等的面积。

推广到卫星：

卫星与地心的连线在相等时间内扫过相等的面积。

物理含义：

  • 卫星在近地点速度最大
  • 卫星在远地点速度最小
  • 角动量守恒的体现

速度公式：

v=μ(2r−1a)v = \sqrt{\mu \left( \frac{2}{r} - \frac{1}{a} \right)}v=μ(r2​−a1​)​

其中 μ=GM\mu = GMμ=GM（地球引力常数），rrr 为瞬时轨道半径，aaa 为半长轴。

开普勒第三定律（周期定律）

表述：行星轨道半长轴的三次方与公转周期的二次方之比为常数。

a3T2=GM4π2=常数\frac{a^3}{T^2} = \frac{GM}{4\pi^2} = \text{常数}T2a3​=4π2GM​=常数

推广到卫星：

卫星轨道半长轴的三次方与运行周期的二次方之比为常数。

应用公式：

T=2πa3μT = 2\pi \sqrt{\frac{a^3}{\mu}}T=2πμa3​​

典型轨道参数：

轨道类型半长轴 aaa周期 TTT特点
低地球轨道（LEO）~6,700 km~90–120 min遥感、通信星座
中地球轨道（MEO）~26,560 km~12 h导航卫星（GPS、北斗）
地球同步轨道（GEO）~42,164 km23h56m4s ≈ 1恒星日通信、广播
地球静止轨道~42,164 km= 24 h（太阳日）相对地面静止

注：地球静止轨道是倾角为0°的地球同步轨道，卫星始终位于赤道上空固定点。

三定律总结

定律核心内容决定因素
第一定律轨道形状为椭圆轨道能量与角动量
第二定律速度随位置变化角动量守恒
第三定律轨道周期与轨道半长轴关系中心天体质量

卫星轨道设计意义

  • 轨道选择：根据任务需求（覆盖、时延、重访周期）选择合适轨道高度
  • 星座部署：利用第三定律精确计算多颗卫星的轨道参数，实现全球覆盖
  • 轨道预测：基于三定律可精确预报卫星位置，支撑测控、通信链路建立

卫星轨道要素

描述卫星椭圆轨道在空间中的位置、形状和方向的基本要素，是轨道确定和预测的基础。

远地点（Apogee）

定义：卫星椭圆轨道上距地心最远的点。

参数：

  • 远地点高度（hah_aha​）：远地点到地球表面的垂直距离
  • 远地点距离（rar_ara​）：远地点到地心的距离，ra=a(1+e)r_a = a(1 + e)ra​=a(1+e)

特点：

  • 卫星速度最小（开普勒第二定律）
  • 通信时延最大、信号最弱

近地点（Perigee）

定义：卫星椭圆轨道上距地心最近的点。

参数：

  • 近地点高度（hph_php​）：近地点到地球表面的垂直距离
  • 近地点距离（rpr_prp​）：近地点到地心的距离，rp=a(1−e)r_p = a(1 - e)rp​=a(1−e)

特点：

  • 卫星速度最大（开普勒第二定律）
  • 大气阻力影响最显著（尤其低轨卫星）

关系公式：

ra+rp=2ar_a + r_p = 2ara​+rp​=2a e=ra−rpra+rp=ra−rp2ae = \frac{r_a - r_p}{r_a + r_p} = \frac{r_a - r_p}{2a}e=ra​+rp​ra​−rp​​=2ara​−rp​​

其中 aaa 为半长轴，eee 为偏心率。

拱线（Line of Apsides）

定义：通过近地点和远地点的直线，即椭圆轨道的长轴。

特点：

  • 拱线方向决定了轨道在轨道平面内的指向
  • 与地心（焦点）共线
  • 是描述轨道平面内方向的重要参考线

升交点（Ascending Node）

定义：卫星从南半球向北半球运动时，穿越赤道平面的点。

特点：

  • 卫星纬度由负变正的临界点
  • 轨道与赤道平面相交的两个点之一

降交点（Descending Node）

定义：卫星从北半球向南半球运动时，穿越赤道平面的点。

特点：

  • 卫星纬度由正变负的临界点
  • 轨道与赤道平面相交的另一个点
  • 升交点：南 → 北（纬度↑）
  • 降交点：北 → 南（纬度↓）

交点线（Line of Nodes）

定义：连接升交点和降交点的直线，即轨道平面与赤道平面的交线。

特点：

  • 交点线通过地心
  • 是轨道平面与赤道平面相交的完整直线
  • 升交点和降交点位于交点线与卫星轨道的交点处

轨道倾角（Orbital Inclination, iii）

定义：卫星轨道平面与地球赤道平面之间的夹角。

计量方式：在升交点处，从赤道平面逆时针测量到轨道平面的角度（0° ≤ iii ≤ 180°）。

倾角类型范围特点
赤道轨道i=0°i = 0°i=0°轨道在赤道平面内，如地球静止轨道
顺行轨道0°<i<90°0° < i < 90°0°<i<90°与地球自转同向，大多数卫星采用
极地轨道i=90°i = 90°i=90°经过南北极，可实现全球覆盖
逆行轨道90°<i<180°90° < i < 180°90°<i<180°与地球自转反向，如部分太阳同步轨道
逆行赤道i=180°i = 180°i=180°理论存在，实际极少使用

重要应用：

倾角典型应用

近地点幅角（Argument of Perigee, ω\omegaω）

定义：在轨道平面内，从升交点到近地点所张的角度，沿卫星运动方向测量。

范围：0°≤ω<360°0° \leq \omega < 360°0°≤ω<360°

物理意义：

  • 确定椭圆轨道在轨道平面内的指向
  • 即拱线（长轴）相对于交点线的方位

几何关系：

ω=升交点→沿运动方向近地点\omega = \text{升交点} \xrightarrow{\text{沿运动方向}} \text{近地点}ω=升交点沿运动方向​近地点

特殊情况：

  • ω=0°\omega = 0°ω=0°：近地点与升交点重合
  • ω=90°\omega = 90°ω=90°：近地点位于升交点之后90°（轨道”最北”处）
  • ω=180°\omega = 180°ω=180°：近地点与降交点重合
  • ω=270°\omega = 270°ω=270°：近地点位于降交点之后90°（轨道”最南”处）

右旋升交点赤经（Right Ascension of Ascending Node, Ω\OmegaΩ）

定义：在赤道平面内，从春分点方向（vernal equinox）到升交点所张的角度，沿地球自转方向（逆时针/右旋）测量。

别名：升交点赤经、RAAN

范围：0°≤Ω<360°0° \leq \Omega < 360°0°≤Ω<360°

物理意义：

  • 确定轨道平面与赤道平面交线（交点线）在赤道平面内的绝对指向
  • 以惯性空间中固定的春分点方向为基准

春分点方向：

  • 地球赤道平面与黄道平面的交线之一
  • 指向白羊座第一点的方向，在惯性空间中近似固定

几何关系：

Ω=春分点方向→右旋升交点\Omega = \text{春分点方向} \xrightarrow{\text{右旋}} \text{升交点}Ω=春分点方向右旋​升交点

平近点角（Mean Anomaly, MMM）

定义：假设卫星以平均角速度 nnn 在圆轨道上运动，从近地点开始经过的时间所对应的角度。

公式：

M=n⋅(t−tp)M = n \cdot (t - t_p)M=n⋅(t−tp​)

其中：

  • n=μa3n = \sqrt{\frac{\mu}{a^3}}n=a3μ​​ 为平均角速度（由开普勒第三定律）
  • tpt_ptp​ 为近地点时刻
  • ttt 为当前时刻

特点：

  • 是假想圆轨道上的角度，卫星实际并不在此位置
  • 随时间均匀变化，便于计算和轨道预测
  • 是连接时间与轨道位置的中间变量

用途：

  • 通过开普勒方程 M=E−esin⁡EM = E - e \sin EM=E−esinE 求解偏近点角 EEE
  • 再由 EEE 求解真近点角 ν\nuν

真近点角（True Anomaly, ν\nuν 或 θ\thetaθ）

定义：在轨道平面内，从近地点到卫星实际位置所张的角度，沿运动方向测量。

范围：0°≤ν<360°0° \leq \nu < 360°0°≤ν<360°

物理意义：

  • 描述卫星在椭圆轨道上的真实瞬时位置
  • 是轨道六要素中唯一随时间快速变化的参数

与平近点角的关系：

  • 通过偏近点角 EEE 建立联系：
    • 开普勒方程：M=E−esin⁡EM = E - e \sin EM=E−esinE
    • 转换公式：tan⁡ν2=1+e1−e⋅tan⁡E2\tan\frac{\nu}{2} = \sqrt{\frac{1+e}{1-e}} \cdot \tan\frac{E}{2}tan2ν​=1−e1+e​​⋅tan2E​

几何关系：

ν=近地点→沿运动方向卫星实际位置\nu = \text{近地点} \xrightarrow{\text{沿运动方向}} \text{卫星实际位置}ν=近地点沿运动方向​卫星实际位置
