# 卫星通信定义
## 一、国际电信联盟（ITU）定义

**1979年ITU世界无线电行政大会**对空间无线电通信的定义为：

> 包括利用一个或多个空间站，或利用一个或多个反射卫星，或空间中其他物体所进行的任何无线电通信，统称为**空间无线电通信**。它可以是空间站和地球站之间的通信，也可以是空间站之间的通信，还可以是地球站相互间通过空间站的转发或反射进行通信。

---

## 二、国内教材与标准定义

### 1. 狭义定义（主流教材）

> **卫星通信（SATCOM）是利用人造地球卫星作为中继站，转发两个或多个地球站之间的无线信号的无线电通信**，是通信技术、计算机技术和航空航天技术相结合的重要成果。

### 2. 广义定义（系统层面）

> 卫星通信可实现地球站之间、地球站与空间站之间、空间站之间通信，以通信卫星为中继站实现天地互联。

### 3. 技术实现定义

> 卫星通信是指利用卫星作为中继站转发无线电磁波，以此来实现两个或多个地球站之间或地球站与航天器之间通信的一种通信方式。

---

## 三、国家标准与军用规范

### 《卫星通信系统通用规范》（GJB 1034-1990）

- 定义：利用人造卫星作为中继站进行通信
    
- 业务分类：固定卫星业务(FSS)、广播卫星业务(BSS)、移动卫星业务(MSS)
    
- 体制分类：频分多址(FDMA)、时分多址(TDMA)、码分多址(CDMA)、空分多址(SDMA)及混合多址方式[1](https://www.tup.tsinghua.edu.cn/upload/books/yz/046120-01.pdf)

---

## 四、最新技术演进定义（2025年）

随着非地面网络（NTN）和直连设备（D2D）技术的发展，卫星通信的定义也在扩展：

> **卫星通信技术**是一种利用人造地球卫星作为中继站来转发无线电波而进行的两个或多个地球站之间的通信，实现从以往单一的地面接入，进阶至空（飞行、浮动基站）天（导航、通信、遥感卫星）地（地面基站）海（船上通信基站）均可接入。

# 卫星通信基本特点
1. 卫星通信系统的服务范围宽，一颗地球同步轨道（GEO）卫星可覆盖约42.4%的地球表面，三颗即可覆盖除极地外的大部分区域；且不受地形、地物等自然条件限制，可在偏远山区、海岛、沙漠、海上平台等地建立通信链路。 
2. 可利用的带宽较宽。实际上，这些频段是离散分配的，并非连续覆盖。卫星通信可用频段包括UHF（300MHz–3GHz）、L（1–2GHz）、S（2–4GHz）、C（4–8GHz）、X（8–12.5GHz）、Ku（12.5–18GHz）、Ka（26.5–40GHz）等，各频段带宽从十几MHz到数GHz不等，且正在向Q/V频段（40–60GHz）扩展。
3. 卫星通信系统与地面通信基础设施相对独立，网络路由简洁。用户之间的通信不依赖于地面通信网，对于地面通信基础设施不足的地区和国家具有重要意义。 
4. 网络建设速度快，地球站部署灵活（VSAT端站可在数小时内建成），在系统容量范围内增加地球站的边际成本较低。但卫星通信系统的总体建设和运维成本仍显著高于地面通信网络，同样带宽的费用远高于地面网。 
5. 由统一业务提供商运营有助于实现系统服务的均匀性和标准化，便于新业务的快速引入和全网推广。 
6. 卫星通信系统独立于地面网络，构成的专网可确保信息安全；同时在自然灾害（地震、洪水等）或突发事件中，当地面网络受损时，卫星通信可作为应急备份和补充手段，具有快速响应和抗毁性强的特点。

# 卫星通信的诞生
## 1. 理论基础（1940s）

- **1945年**：英国科幻作家 **亚瑟·克拉克（Arthur C. Clarke）** 在《无线电世界》杂志发表文章，首次提出**地球同步轨道卫星**用于通信的构想。
- 他设想在距地面约 **35,786 km** 的赤道上空部署三颗卫星，即可覆盖全球除极地外的通信。

## 2. 技术验证（1950s–1960s）

| 时间        | 事件                          | 意义                        |
| --------- | --------------------------- | ------------------------- |
| **1957年** | 苏联发射 **斯普特尼克1号（Sputnik 1）** | 人类首颗人造卫星，开启太空时代           |
| **1960年** | 美国发射 **回声1号（Echo 1）**       | 首个被动反射通信卫星（气球卫星）          |
| **1962年** | 美国发射 **电星1号（Telstar 1）**    | 首颗**有源中继**通信卫星，实现跨大西洋电视直播 |
| **1963年** | 美国发射 **辛康2号（Syncom 2）**     | 首颗进入地球同步轨道的卫星             |
| **1964年** | 美国发射 **辛康3号（Syncom 3）**     | 首颗**地球静止轨道**卫星，成功转播东京奥运会  |

## 3. 商业化与国际化（1960s–1970s）

- **1964年**：成立 **国际通信卫星组织（INTELSAT）**，推动卫星通信全球商业化。
- **1965年**：INTELSAT发射 **"Early Bird"（晨鸟号）**，首颗商业通信卫星，提供欧美间240路电话或1路电视传输。
- **1970s**：C波段、Ku波段卫星电视广播开始普及；海事卫星通信（INMARSAT，1979年）成立。

## 4. 关键里程碑

- **轨道高度**：地球同步轨道（GEO）约 **35,786 km**；后续发展出中轨道（MEO）和低轨道（LEO）星座。
- **技术演进**：从模拟通信 → 数字通信 → 高通量卫星（HTS）→ 低轨巨型星座（如Starlink）。
# 卫星术语
## 地面站（Ground Station / Earth Station）

**定义**：位于地球表面，用于与卫星进行无线电信号收发和数据交换的设施。

**组成**：
- 天线系统（抛物面天线为主）
- 射频收发设备（高功率放大器、低噪声放大器）
- 调制解调器与基带处理设备
- 跟踪、遥测和指令（TT&C）系统

**分类**：
| 类型 | 特点 | 典型应用 |
|------|------|----------|
| 关口站（Gateway） | 大口径天线（数米至十几米），高功率 | 卫星互联网核心节点、广播上行 |
| VSAT终端 | 甚小口径终端（0.6–2.4米），低成本 | 企业专网、偏远地区接入 |
| 便携式/移动站 | 可快速部署，轻量化 | 应急通信、军事、新闻直播 |
| 测控站 | 专用于卫星管理 | 轨道测定、指令发送、状态监测 |

---

## 上行链路（Uplink）

**定义**：从**地面站向卫星**传输信号的通信链路。

**关键参数**：
- **频率**：通常高于下行链路（如C波段上行6 GHz / 下行4 GHz；Ku波段上行14 GHz / 下行11–12 GHz）
- **功率**：需克服自由空间损耗，地面站发射功率较高（瓦级至千瓦级）
- **调制方式**：QPSK、8PSK、16APSK、32APSK等

**特点**：
- 信号从地面强功率发射，穿越大气层到达卫星
- 易受雨衰影响（尤其Ku/Ka频段）
- 卫星接收灵敏度受限，需地面站提供足够链路余量

---

## 下行链路（Downlink）

**定义**：从**卫星向地面站**传输信号的通信链路。

**关键参数**：
- **频率**：通常低于上行链路
- **功率**：受卫星能源和散热限制，卫星发射功率有限（瓦级至数百瓦）
- **覆盖**：通过卫星天线波束设计实现区域或全球覆盖

**特点**：
- 信号从卫星弱功率发射，覆盖广大区域
- 地面站需高灵敏度接收（低噪声放大器LNA/LNB）
- 广播业务中，一个下行信号可被多个地面站同时接收
- 同样受雨衰、大气吸收等影响

**链路预算关系**：
> 系统设计中，上行链路与下行链路需分别计算载噪比（C/N），最终合并为总链路质量。

---

## 卫星平台（Satellite Bus / Platform）

**定义**：卫星中承载并支持**有效载荷**正常工作的通用化基础结构部分，又称"卫星公用舱"或"服务舱"。

**主要子系统**：

| 子系统 | 功能 |
|--------|------|
| **结构系统** | 提供机械支撑，承受发射载荷 |
| **电源系统** | 太阳能电池阵 + 蓄电池组，提供能源 |
| **姿态与轨道控制（AOCS）** | 维持卫星姿态稳定和轨道位置 |
| **推进系统** | 轨道转移、位置保持、姿态调整 |
| **热控系统** | 管理卫星温度，保障设备正常工作 |
| **遥测、跟踪与指令（TT&C）** | 与地面测控站交互，传输状态数据、接收指令 |

---

## 有效载荷（Payload）

**定义**：有效载荷是卫星上**直接执行特定任务功能**的设备或系统，是卫星的"核心使命"所在，区别于提供通用支撑的卫星平台。

> 简单理解：**平台让卫星"活着"，载荷让卫星"干活"**。

### 通信卫星的有效载荷

#### 1. 透明转发器（ Bent Pipe / 弯管式 ）

| 特点   | 说明                 |
| ---- | ------------------ |
| 工作原理 | 仅对信号进行频率变换和放大，不做处理 |
| 类比   | 像"镜子"或"中继站"，原样转发   |
| 优点   | 结构简单、时延小、成本低       |
| 缺点   | 无法抗干扰、频谱效率低、无法星上交换 |

**信号流程**：

地面上行信号 → 接收天线 → 低噪放 → 下变频 → 高功放 → 发射天线 → 地面下行

### 2. 处理转发器（ Regenerative / 再生式 ）

| 特点 | 说明 |
|------|------|
| 工作原理 | 在星上解调、处理、再调制后转发 |
| 类比 | 像"路由器"，具备信号再生能力 |
| 优点 | 抗干扰、可星上交换、频谱效率高、支持波束间路由 |
| 缺点 | 复杂度高、功耗大、成本较高 |

**信号流程**：

地面上行信号 → 接收 → 解调 → 基带处理/交换/路由 → 再调制 → 放大发射

### 有效载荷核心组成

| 组件                   | 功能                                |
| -------------------- | --------------------------------- |
| **天线系统**             | 收发信号，决定覆盖区域（全球波束、区域波束、点波束）        |
| **转发器（Transponder）** | 接收、变频、放大、发射信号的基本单元                |
| **星上处理器（OBP）**       | 对信号进行解调、交换、路由等处理                  |
| **放大器（SSPA/TWTA）**   | 固态功率放大器（SSPA）或行波管放大器（TWTA），提供发射功率 |

### 不同卫星的有效载荷示例

| 卫星类型 | 有效载荷 | 任务 |
|----------|----------|------|
| **通信卫星** | 通信转发器、天线 | 电话、电视、数据传输 |
| **遥感卫星** | 光学相机、雷达、红外传感器 | 对地观测、资源调查 |
| **导航卫星** | 原子钟、导航信号发生器 | 定位、授时、导航 |
| **气象卫星** | 扫描辐射计、垂直探测器 | 气象预报、灾害监测 |
| **科学卫星** | 粒子探测器、望远镜 | 空间科学实验 |
